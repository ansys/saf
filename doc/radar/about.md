# How to use the Technology Radar

The SAF Technology Radar gives an overview of the technologies, tools, and practices used in SAF, and how we recommend using them when building solutions.

## Quadrants

- **Staples**: Languages, frameworks, and services used to build software.
- **Security & Compliance**: Tools that streamline and enforce security and compliance rules.
- **Platforms & Operations**: Platforms and services for operating and scaling applications.
- **Tools & Patterns**: Productivity tools and patterns for projects of any size.

## Rings

- **Adopt**: Recommended default for SAF solutions.
- **Trial**: Worth using on projects that can handle some risk.
- **Assess**: Worth exploring to understand its impact.
- **Hold**: Not recommended for new work.

Items can be filtered by tag. Each item keeps a history of how its ring changed over time.

## Contributing

The radar content is maintained in the [SAF repository](https://github.com/ansys/saf/tree/main/doc/radar/radar). To propose a change, open a pull request that adds or edits a Markdown file in a new release folder.
