**Docker Compose** is a tool for defining and running multi-container Docker applications. It has been adopted as the standard containerization approach for SAF-powered applications, providing pre-configured deployment options in the solution templates generated by the SAF CLI.

## SAF Integration

Docker Compose files are included in the SAF solution template, enabling developers to run applications in a fully containerized manner with minimal setup. This provides:

- **Consistent Development Environments**: Eliminates "works on my machine" issues by containerizing all dependencies
- **Quick Setup**: Developers can spin up entire application stacks with a single command
- **Reproducible Deployments**: Identical configuration across development, testing, and production environments
- **Service Orchestration**: Manages multiple containers (application, databases, message queues, etc.) as a unified application

## Supported Configurations

The SAF CLI templates include multiple Docker Compose configurations to support different deployment scenarios:

- **Standalone**: Single-node deployment for local development and testing
- **Standalone with HPS**: Integration with Ansys HPS (High Performance Computing Platform Services) for compute-intensive workloads
- **Distributed Deployment Templates**: Multi-node configurations for scalable, production-like environments

These pre-configured templates allow developers to choose the appropriate deployment topology based on their requirements, from simple local development to complex distributed architectures, all while maintaining consistency in how applications are containerized and orchestrated.
