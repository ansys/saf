**Docker** is a platform for developing, shipping, and running applications in containers. It has been adopted as the fundamental containerization technology for SAF-powered applications, providing consistent, portable, and isolated runtime environments.

## SAF Integration

Docker is deeply integrated into the SAF ecosystem through the solution template generated by the SAF CLI. The template includes pre-configured **Dockerfiles** that enable developers to containerize their applications with very limited additional configuration.

## Supported Configurations

The SAF CLI templates provide Dockerfiles optimized for different deployment scenarios:

- **Standalone**: Single-container deployment for local development and simple applications
- **Standalone with HPS**: Specialized configuration for integration with Ansys HPS (High Performance Computing Platform Services)
- **Distributed Deployment Templates**: Multi-container configurations designed for microservices and distributed architectures

## Docker Compose Integration

Docker works hand-in-hand with Docker Compose in SAF templates. While Docker handles individual container definitions (via Dockerfiles), Docker Compose orchestrates multi-container applications, defining how services interact and scale together.

By providing production-ready Dockerfiles out of the box, SAF enables developers to adopt containerization best practices from day one, accelerating the path from development to deployment.
