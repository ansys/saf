[OpenTelemetry](https://opentelemetry.io/) is a vendor-neutral, open source framework for generating and exporting traces, metrics, and logs.

Smartly instrument your code will ease monitoring and diagnostic, especially for distributed scenario. Show case how smart and lightweight code base instrumentation can surface meaningful insights to monitor and diagnose your application.
