**Python** is a core programming language in the SAF technology stack, widely adopted for building APIs, backend services, testing frameworks, and automation tooling. As a versatile, high-productivity language with rich ecosystem support, Python enables rapid development of scalable applications and infrastructure automation.

Currently supporting 3.11, 3.12, 3.13 and 3.14. Support for 3.10 was dropped because it reached its end of life.
