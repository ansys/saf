# Customize installer branding

- `favicon.ico` (Windows) / `favicon.png` (Linux): Customizes the installer executable icon and the installer app icon (top-left/title bar and taskbar).
- `shortcut.ico` (Windows) / `shortcut.png` (Linux): Customizes the desktop shortcut icon created by the installer.
- `installer_ui_logo.png`: Customizes the logo shown in the installer UI.
