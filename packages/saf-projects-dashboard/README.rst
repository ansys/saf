About
=====

Projects Dashboard is a Dash component for managing GLOW projects with full
CRUD operations. It integrates with SAF/GLOW backend services and provides
import/export support for ``.safx`` project files.

Installation
============

Install from PyPI:

.. code:: shell

   pip install ansys-saf-projects-dashboard

For editable/local development installs:

.. code:: shell

   pip install -e .
