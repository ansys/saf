AsyncStorageScopeBase#

class ansys.bdm.base.base_async_storage_scope.AsyncStorageScopeBase#

Bases: ansys.bdm.api.iasync_storage_scope.IAsyncStorageScope

A partial implementation of IAsyncStorageScope that provides implementations of some methods based on other more fundamental methods. AsyncStorageScopeBase can be used as a base class for implementations of IAsyncStorageScope.

The handle to the data to realize

The name of an encoding. When this argument is not None the bytes of entity will be read using that encoding.

str

the contents of the blob referenced by entity in text form with the encoding determined in order of preference: - the encoding argument if not None - the encoding field of the entity argument if set - the BOM of the referenced entity if it contains one; or - UTF-8
