AEDT Product Instance Manager#

Objective

Creation of a product instance manager for Ansys Electronics Desktop (AEDT) products, such as Maxwell 2D.

Source code for this example is in the solution-examples repository.

Objective#

Ansys Electronics Desktop is a unified simulation platform that integrates multiple Ansys solvers for electromagnetic, thermal, and circuit analysis, enabling seamless collaboration and coupled physics simulations.

This example shows how to create a product instance manager for AEDT products, such as Maxwell 2D, using the SAF framework. The product instance manager allows you to manage the lifecycle of an AEDT product instance, including starting, stopping, and accessing the product’s API.

AEDT Product Instance Manager (Maxwell 2D)#

Component

Description

Step model

  • Long-running transaction to initialize the product instance.

  • Transaction to shutdown the product instance.

  • Transaction to call the AEDT API to add a rectangle to the design.

  • Transaction to call the AEDT API to analyze the design.

User interface

  • Button to initialize the product instance.

  • Button to shutdown the product instance.

  • Button to add a rectangle to the design.

  • Button to analyze the design.

Prerequisites#

Note

This example requires the AEDT 2025 R1 (25R1) product to be installed on your machine. To work with an AEDT product instance, be sure to install the aedt extra from the ansys-saf-product-manager package. You can do this by manually editing your pyproject.toml.

ansys-saf-glow-engine = {version = "^2.30", extras = ["pim"]}
ansys-saf-product-manager = {version = "^0.5", extras = ["aedt"]}

This will install the supported version of PyAEDT to control the AEDT product instances. This example uses PIM as the product instance management system. If you want to use HPS instead, replace the pim extra with hps. For more information, see Configuration.

Solution#

To create a product instance manager for AEDT products and interact with it, walk through the following sequence of tabs.

Define the step model.

Define the step model
  • There are two transactions that are used to manage the product instance lifecycle: initialize_maxwell_2d_instance and exit_aedt.

    • The first one initializes the product instance, while the second one shuts it down.

    • The initialize_maxwell_2d_instance long-running transaction is decorated with @create_instance to create an instance of the AEDT product manager, in this case, Maxwell2DManager.

    • The exit_aedt transaction is used to shutdown the AEDT instance.

  • The other two transactions, add_rectangle and run_analysis are used to add a rectangle to the design and to analyze it, respectively.

aedt_step.py#
 5from ansys.saf.glow.solution import StepModel, StepSpec, create_instance, instance, long_running, transaction
 6from ansys.saf.glow.solution.beta.aedt import Maxwell2DManager
 7
 8
 9class Maxwell2DSetupVerificationStep(StepModel):
10    """Step to verify the setup of Maxwell 2D instance."""
11
12    aedt_version: str = "251"
13    origin: list[float] = [0, 0, 0]
14    dimension: list[float] = [10, 10]
15
16    @transaction(self=StepSpec(download=["aedt_version"]))
17    @create_instance("maxwell_2d_instance", Maxwell2DManager)
18    @long_running
19    def initialize_maxwell_2d_instance(self, maxwell_2d_instance: Maxwell2DManager) -> None:
20        """Initialize the Maxwell 2D instance."""
21        maxwell_2d_instance.initialize(version=self.aedt_version)
22
23    @transaction(self=StepSpec(download=["origin", "dimension"]))
24    @instance("maxwell_2d_instance")
25    def add_rectangle(self, maxwell_2d_instance: Maxwell2DManager) -> None:
26        """Add a rectangle to the Maxwell 2D instance."""
27        primitives = maxwell_2d_instance.instance.modeler.primitives  # type: ignore
28        primitives.create_rectangle(self.origin, self.dimension)  # type: ignore
29
30    @transaction(self=StepSpec())
31    @instance("maxwell_2d_instance")
32    def run_analysis(self, maxwell_2d_instance: Maxwell2DManager) -> bool:
33        """Run the analysis on the Maxwell 2D instance."""
34        return maxwell_2d_instance.instance.analyze()  # type: ignore
35
36    @transaction(self=StepSpec())
37    @instance("maxwell_2d_instance")
38    def exit_aedt(self, maxwell_2d_instance: Maxwell2DManager) -> None:
39        """Shutdown the AEDT instance."""
40        maxwell_2d_instance.shutdown()

Define the initialization of the product instance callback

  • When the Initialize Instance button is clicked, the initialization callback is activated.

  • The callback starts the long-running transaction to initialize the product instance.

  • After waiting for 60 seconds to allow the product instance to be initialized, it updates the UI with the result.

initialization callback from aedt_instance_page.py#
 96@callback(
 97    Output("init_result", "children"),
 98    Input("init_button", "n_clicks"),
 99    State("url", "pathname"),
100    prevent_initial_call=True,
101)
102def init(n_clicks: int, pathname: str):
103    """Initialize the Maxwell 2D instance."""
104    project = DashClient[ExamplesSolution].get_project(pathname)
105    step = project.steps.aedt_step
106    step.initialize_maxwell_2d_instance().wait(timeout=60)
107    return "Maxwell 2D Instance initialized successfully."
Define the add_rectangle transaction button

  • The callback starting the transaction adds a rectangle to the design based on the step values.

  • This values can be set or accessed with project.steps.aedt_step.origin and project.steps.aedt_step.dimension.

add_rectangle transaction button callback from aedt_instance_page.py#

116def add_rectangle(n_clicks: int, pathname: str):

120    step.add_rectangle()

Define the analyze transaction button

  • The callback starting the transaction analyzes the current design passed.

  • This transaction returns a boolean value that updates the UI after the transaction has finished.

analyze transaction button callback from aedt_instance_page.py#
124@callback(
125    Output("result", "children"),
126    Input("analyze_button", "n_clicks"),
127    State("url", "pathname"),
128    prevent_initial_call=True,
129)
130def analyze(n_clicks: int, pathname: str):
131    """Run the analysis on the Maxwell 2D instance."""
132    project = DashClient[ExamplesSolution].get_project(pathname)
133    step = project.steps.aedt_step
134    value = step.run_analysis()
135    return f"Result: {'Analysis Successful.' if value is True else 'Analysis Failed.'}"
Define the shutdown transaction button

  • When the Shutdown Instance button is clicked, the shutdown callback is activated.

  • The callback starts the transaction to shutdown the product instance.
