##########
Contribute
##########

.. vale off

Thank you for your interest in contributing to SAF! Contributions are welcome
to make the project better, whether it's fixing bugs, adding new features, or
improving documentation. Below are the guidelines to follow when contributing.

.. vale on

.. important::

    This project adheres to the `Contributor Covenant Code of Conduct <https://www.contributor-covenant.org/version/2/1/code_of_conduct>`_.
    By participating, you agree to uphold this code.


.. admonition:: Prerequisite
    :class: note

    To contribute to the SAF project, you need a GitHub account. For instructions, see the GitHub documentation on how to `create a GitHub account <https://docs.github.com/en/get-started/signing-up-for-github/signing-up-for-a-new-github-account>`_.



To learn how you can contribute to the SAF project, review the documentation relevant to your role:
