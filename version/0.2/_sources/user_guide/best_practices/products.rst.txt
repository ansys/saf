Ansys products
###############

When working with Ansys products in your solution, you may be tempted to use the ``pyansys`` libraries to interact with the product instances directly.
However, to ensure better maintainability, scalability, and integration with the overall SAF GLOW Engine framework, it is recommended to use the Product Instance Management system provided by SAF GLOW Engine.
This system abstracts the complexities of managing product instances and provides a consistent interface for interacting with them.

For more information on the Product Instance Management, refer to the following `documentation <https://saf.glow.docs.solutions.ansys.com/version/stable/user_guide/using_ansys_products/product_instance_management/usage.html>`_.
