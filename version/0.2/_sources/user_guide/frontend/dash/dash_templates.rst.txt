.. _dash_templates:

Dash templates
##############

The starting point for creating a SAF-based solution is the solution template located in the SAF CLI. This template is instantiated when the command
``saf new`` is invoked. Two options are available for the frontend of the solution: ``dash`` and ``none``.

When the ``dash`` option is selected, the solution template will include a Dash frontend. This frontend is built using Plotly Dash, and mainly based
on the following public libraries:
