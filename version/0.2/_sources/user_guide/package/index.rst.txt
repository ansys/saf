Package
########

SAF provides two ways to package your solution for distribution.

.. grid:: 3
   :gutter: 4
   :class-container: onboarding-cards

   .. grid-item-card:: :material-outlined:`install_desktop;1.75em` Build a distributable desktop installer
      :class-card: highlight-card
      :link-type: doc
      :link: installer
      :shadow: lg

      Create a standalone executable installer that bundles your solution and its dependencies for end-user deployments.

   .. grid-item-card:: :material-outlined:`archive;1.75em` Archive a solution
      :class-card: highlight-card
      :link-type: doc
      :link: archive
      :shadow: lg

      Generate a ``.saf`` archive of your solution's source code for sharing or version control.
