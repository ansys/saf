Dash frontend#

SAF is frontend agnostic, meaning that you can use any frontend technology to build the user interface of your solution. However, Plotly Dash is the default frontend technology used for building SAF-based solutions. It is a powerful and flexible framework for building web applications in Python, and it is well-suited for data visualization and interactive applications. Plotly Dash is also the frontend technology most integrated with SAF, making it the recommended choice for building the frontend of your solution.
