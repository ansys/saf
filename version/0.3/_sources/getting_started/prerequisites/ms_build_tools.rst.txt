Microsoft C++ Build Tools
#########################

Microsoft C++ Build Tools are required to build the solution installer.
If you need to build Python from source, install the Visual Studio Build Tools version that matches your Python version
(for example, VS 2019 for Python 3.10/3.11 and VS 2022 for Python 3.12).

#. Download Microsoft C++ Build Tools:

   Download `Microsoft C++ Build Tools 2017 <https://aka.ms/vs/15/release/vs_buildtools.exe>`_ (version 15).

#. Install Microsoft C++ Build Tools:

   Run the downloaded installer. In the Visual Studio Installer:

   a. Select the **Desktop development with C++** workload.
   b. Under **Individual components** or **Optional** components, ensure the **VC++ 2015.3 v14.00 (v140) toolset for desktop** checkbox is checked.
   c. Proceed with the installation.
