Get started with Plotly Dash
################################

To start using SAF with the Plotly Dash frontend, you should learn the basics of Dash. The `official Dash documentation <https://dash.plotly.com/>`_ is a great place to start,
as it provides a comprehensive overview of the framework and its features.

In particular, we recommend that you review the following sections of the documentation:
