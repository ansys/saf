Available icons
===============

The following icons are available in the ``IconNames`` enumeration. Each card
shows the rendered icon (in dark grey), the Python constant name
(``IconNames.<NAME>``), along with the corresponding icon-set identifier string
that is passed to the icon-set stylesheet.
