SAF examples
============

These examples demonstrate the usage of Dash Super Components that
integrate directly with the Solutions Application Framework (SAF) GLOW API.
They embed a lightweight mock GLOW server so you can run them without a real SAF installation.

Download any example as a Python script or Jupyter notebook and run it on your machine once DDash Super Components is installed.


.. seealso::


 For examples on how to use  Dash Super Components within a full SAF solution, see the
 `showcase application <https://github.com/ansys/saf/tree/main/packages/dash-super-components/examples/showcase_all>`_
 in the repository.
